The first Arikan release: a fork of Mikan that carries an Arikan panel's WL entries by itself.

- A subscription's `WL` connection points at `127.0.0.1:9000`, and the app now runs the TURN client that has to answer there. No separate program, and no copying `peer`, `vk-link`, `listen`, `n` and `udp` into a helper app by hand.
- The app has its own identity — **Arikan**, application ID `ru.arikan.app`, signed with its own key — so it installs **next to** the official Mikan instead of trying to replace it. Subscriptions and settings do not carry over between the two.
- Importing or updating a subscription also asks the panel for its TURN parameters (`?format=turn`) and keeps them with the profile. Loading a profile starts one client per node the profile actually routes through; stopping the VPN stops them, so a client lives exactly as long as the tunnel it feeds.
- If VK asks for a captcha, the WL screen offers a button that opens the captcha page inside the app. Once it is answered the client carries on by itself.
- This build ships **arm64-v8a** and **armeabi-v7a**; the emulator architectures (x86, x86_64) are a later build.

For most phones, download **arikan-alpha-arm64-v8a.apk**. The **universal** APK contains both architectures, and the armeabi-v7a APK is for older 32-bit devices. All APKs are signed release builds; file hashes are in **SHA256SUMS.txt**.

Первый релиз Arikan — форка Mikan, который сам обслуживает WL-записи панели Arikan.

- Подключение `WL` в подписке указывает на `127.0.0.1:9000`, и клиент TURN, который должен отвечать по этому адресу, теперь работает внутри приложения. Отдельная программа не нужна, и не нужно вручную переносить `peer`, `vk-link`, `listen`, `n` и `udp`.
- У приложения своя личность — **Arikan**, идентификатор `ru.arikan.app`, своя подпись, — поэтому оно ставится **рядом** с официальным Mikan, а не поверх него. Подписки и настройки между ними не переносятся.
- При импорте и обновлении подписки приложение дополнительно запрашивает у панели параметры TURN (`?format=turn`) и хранит их вместе с профилем. При включении профиля поднимается по клиенту на каждую ноду, через которую профиль действительно ходит; при выключении VPN они останавливаются — клиент живёт ровно столько, сколько живёт туннель.
- Если VK просит капчу, на экране «WL» появляется кнопка: страница капчи открывается внутри приложения. После ответа клиент продолжает работу сам.
- В этой сборке **arm64-v8a** и **armeabi-v7a**; архитектуры эмулятора (x86, x86_64) — в следующих сборках.

Для большинства телефонов нужен **arikan-alpha-arm64-v8a.apk**. APK **universal** содержит обе архитектуры, **armeabi-v7a** — для старых 32-битных устройств. Все APK — подписанные release-сборки, хеши файлов в **SHA256SUMS.txt**.
